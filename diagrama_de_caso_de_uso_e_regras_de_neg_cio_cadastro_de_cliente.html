Especificação das Regras de Negócio (RN01 a RN06)

Critérios normativos, restrições e validações obrigatórias que regem o ciclo de vida do cadastro de clientes.

6 Regras Documentadas
RN01 Integridade

Unicidade de Documento (CPF/CNPJ)

Não é permitido cadastrar dois clientes distintos com o mesmo número de CPF (Pessoa Física) ou CNPJ (Pessoa Jurídica). O documento atua como chave única de identificação fiscal no sistema.

Impacto no Sistema:

Bloqueia registros duplicados no banco de dados e aciona fluxo de exceção informando cadastro existente.

UC01 - Realizar Cadastro UC04 - Exibir Erro/Duplicidade
RN02 Validação

Validação de Dados e Dígitos Verificadores

O sistema deve validar matematicamente os dígitos verificadores do CPF/CNPJ, a sintaxe do endereço de e-mail e consultar o CEP na base postal para preenchimento e validação do logradouro antes de salvar.

Impacto no Sistema:

Evita inconsistências cadastrais, reduz erros de digitação e garante entregas/comunicações válidas.

UC02 - Validar Dados UC03 - Consultar CEP
RN03 Completude

Obrigatoriedade de Campos Essenciais

Para efetivar a inclusão ou atualização cadastral, são obrigatórios: Nome Completo ou Razão Social, CPF/CNPJ, Data de Nascimento/Abertura, E-mail, Telefone de contato e Endereço completo (CEP, Logradouro, Número, Cidade e UF).

Impacto no Sistema:

Impede a submissão de formulários incompletos e destaca os campos pendentes ao usuário.

UC01 - Realizar Cadastro UC06 - Alterar Dados
RN04 Conformidade Legal

Maioridade Civil para Autocadastro (PF)

Clientes Pessoa Física devem possuir idade igual ou superior a 18 anos completos na data do registro para realizar o autocadastro de forma autônoma e assumir obrigações comerciais.

Impacto no Sistema:

Calcula a idade a partir da data de nascimento e bloqueia o autocadastro de menores de idade.

UC01 - Realizar Cadastro UC02 - Validar Dados UC04 - Exibir Erro
RN05 Retenção de Dados

Exclusão Lógica (Inativação de Registro)

Clientes que já possuem histórico de pedidos, notas fiscais ou movimentações financeiras não podem ser excluídos fisicamente do banco de dados, devendo apenas ter seu status alterado para "Inativo".

Impacto no Sistema:

Preserva a integridade referencial do histórico fiscal/contábil e impede novas compras pelo perfil inativo.

UC05 - Consultar Cliente UC08 - Inativar Cliente
RN06 Segurança & LGPD

Autenticação para Consulta e Alteração

Apenas usuários devidamente autenticados (o próprio titular da conta ou um atendente/administrador autorizado) podem visualizar dados sensíveis, alterar informações cadastrais ou inativar registros.

Impacto no Sistema:

Exige login válido antes de liberar operações de leitura/escrita e registra log de auditoria das alterações.

UC06 - Alterar Dados UC07 - Autenticar Usuário UC08 - Inativar Cliente

Legenda de Relacionamentos UML

Convenções utilizadas no Diagrama de Caso de Uso para o módulo de Cadastro de Cliente.

Associação Direta (Linha Sólida) Conecta um ator diretamente ao caso de uso que ele inicia ou participa (ex.: Cliente realiza UC01 - Realizar Cadastro ou Atendente executa UC08 - Inativar Cliente).
<<include>> (Inclusão Obrigatória) Indica comportamento obrigatório incorporado ao caso de uso base (ex.: UC01 inclui UC02 - Validar Dados e UC03 - Consultar CEP; UC06 e UC08 incluem UC07 - Autenticar Usuário).
<<extend>> (Extensão Condicional) Representa um comportamento opcional ou fluxo de exceção acionado sob condição específica (ex.: UC04 - Exibir Erro de Validação/Duplicidade estende UC01 quando o CPF já existe ou é inválido).

Atores e Responsabilidades

Perfis humanos e sistemas externos que interagem com o Cadastro de Cliente.

Ator Classificação Casos de Uso & Atribuições
Cliente Primário Realiza o próprio autocadastro (UC01), consulta seus dados (UC05) e atualiza suas informações mediante login (UC06).
Atendente / Administrador Primário Cadastra clientes presencialmente/suporte (UC01), pesquisa registros (UC05), edita dados (UC06) e inativa cadastros (UC08).
API Externa (CEP / Receita) Secundário Serviço externo acionado pelo sistema para validar situação cadastral de CPF/CNPJ (UC02) e preencher endereços via CEP (UC03).
